開門收客前，逐項打勾

上線前最終檢查清單

照順序一項一項確認，全部打勾再開放給客戶。每一項都寫了「為什麼重要」和「怎麼確認」。看不懂的直接把該項截圖問工程師。

怎麼用這張清單

每一項前面有一個框，做好就打勾（在瀏覽器點一下即可）。標 必做 的沒完成先不要公開網站；標 資安 的是保護你和客戶資料的關鍵。可以「列印 / 另存 PDF」隨身對照。

一、資料庫地基

補跑兩行資料庫指令 必做

新版程式需要兩個資料庫欄位；沒有的話「付款開通」會卡住、「重設密碼」會失敗。

怎麼做：Supabase → 左邊 SQL Editor → 貼上下面兩行 → 按 Run（看到 Success 就好，可重複跑）：

ALTER TABLE orders ADD COLUMN IF NOT EXISTS fulfilled_at timestamptz;
ALTER TABLE users  ADD COLUMN IF NOT EXISTS password_changed_at timestamptz;

確認資料庫「對外上鎖」有開（RLS） 必做 資安

沒上鎖的話，別人可能用公開金鑰撈走你的全部客戶資料。這是最重要的一道鎖。

怎麼做：SQL Editor 貼上下面，按 Run，看每一列的 relrowsecurity 是不是都 true；有任何一個 false，就去把 db/enable_rls.sql 整份貼上跑一次。

select relname, relrowsecurity from pg_class
where relname in ('users','orders','user_courses','user_downloads',
                  'site_settings','course_comments','rate_limits');

二、讓電腦幫你自動體檢

跑一次「一鍵驗收」 資安

它會自動檢查環境變數、資料庫、限流、儲存空間、管理員帳號，還會實測「資料庫有沒有上鎖」。看到「全部必要項目通過」最安心。

怎麼做：這步需要一點電腦操作。若你全程用網頁設定、沒碰過指令，請把這項交給工程師：在 bds-web 資料夾執行 npm run verify，把畫面截圖給你即可。有紅色 ✗ 就照它的指示補。

三、金流（收錢）

關掉「免費開通」測試開關 必做 資安

這個開關若開著，有心人可能不付錢就開通課程。

怎麼做：Netlify → 環境變數 → 確認 ENABLE_PAYMENT_SIMULATION 是 false（或整個刪掉）。改完記得 Trigger deploy。

金流切換成「正式」 必做

測試端點收不到真錢；上線收真錢一定要換成正式的。

怎麼做：確認 PayUni 商家審核通過後，把 NEXT_PUBLIC_PAYUNI_UPP_URL 換成正式端點、金鑰換成正式那組，重新部署。

用真卡買一筆測試 必做

確認整條路走得通：付款成功 → 自動開通 → 收到通知信。這是收錢最關鍵的一條路。

怎麼做：用一張真卡買一個最便宜的商品，確認上面三步都對，然後退刷。（系統設計上同一筆只會開通一次，不會重複扣款。）

四、寄信（客戶收得到信）

寄件網域已驗證、不是測試信箱 必做

沒驗證的話，客戶收不到「驗證信 / 重設密碼信」，就沒辦法登入——等於把客戶擋在門外。

怎麼做：確認 RESEND_FROM_EMAIL 是你自己的網域（例如 no-reply@你的網域），不是 onboarding@resend.dev。實測：用另一個信箱去 /signup 註冊 → 該信箱收得到驗證信 → 點了能登入。

五、影片與付費內容保護

付費內容用私有空間交付 資安

保護你的收入：影片、下載檔、教材不會被複製連結到處轉發。

怎麼做：系統已自動處理——之後上傳的付費影片/下載檔/教材會自動放進私有空間、只發會過期的短連結。若你先前上傳過測試的付費檔，請重新上傳一次，舊的才會受到保護。

六、備份與不中斷

每日自動備份已生效 必做

萬一資料出事，救得回來。

怎麼做：GitHub → Actions → 「每日資料庫備份」→ Run workflow 跑一次，看到綠色打勾、且下方 Artifacts 出現備份檔才算成功。（連線字串記得用 Session pooler 那條，見開站手冊。）

保活機制已開 必做

網站閒置太久，免費資料庫會「睡著」，客戶會連不上。

怎麼做：確認開站手冊步驟 9A 的保活已設定並測試成功。

七、換成你的品牌

品牌與範例資料整理好

別讓客戶看到範例課程或別人的名字。

怎麼做：後台「設定」改好站名、Logo、主色、聯絡信箱、FAQ、公告；刪掉範例課程與範例訂單；網址 NEXTAUTH_URL 已是你真正的網域。

八、搬家（有舊學員才需要）

舊學員 / 影片搬遷完成並核對

確保老客戶的帳號與買過的課都在，且看得到。

怎麼做：依《搬家手冊》執行（建議由賣方/工程師操作）。抽查 3～5 位不同課的學員確認看得到買過的課。新站確認一切正常前，先別停用舊平台。

✅ 全部打勾之後

你就可以安心把網站公開給客戶了。之後只要偶爾確認「備份有在跑、信寄得出去」即可。若哪一項卡住，把那一項截圖問工程師，資訊已足夠他判斷。

此清單為賣方交付買家自我檢查用；技術項目可請工程師協助。
