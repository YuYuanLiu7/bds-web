售後服務範圍說明

這份說明買方在購買本系統後，「哪些由賣方協助、哪些需另外付費」，讓雙方對售後有清楚共識。

賣方：＿＿＿＿＿＿　買方：＿＿＿＿＿＿　交付日：＿＿年＿＿月＿＿日

（黃底空格請雙方於成交時填寫；本文件一式兩份，雙方各執一份。）

一、免費保固 免費

期間：交付日起 ＿＿ 個月內。

此期間內，若是「賣方交付的程式本身有缺陷」（原本該正常運作卻出錯），賣方免費修正。例如：金流流程異常、後台功能報錯、頁面壞掉等屬程式面的問題。

二、一次性設定協助 免費

期間：交付日起 ＿＿ 天內。

協助買方完成初次上線設定的疑問（照《開站手冊》操作卡關時）。超過期間或重複詢問同一操作，屬下方「教學/操作支援」。

三、不含 / 需另外收費 另計

  • 第三方服務的問題與費用：Supabase、Netlify、Resend、Bunny、PayUni、網域等的帳號申請、審核、故障、以及它們的付費方案費用（例如 Bunny 影片費、網域續約、免費額度用完後的升級），皆由買方自行負責與支付。
  • 教學 / 操作支援（超出上述期間）：如「怎麼改公告」「怎麼上架課程」等後台操作教學。
  • 功能客製 / 新增功能：與原交付規格不同的修改或加購功能。
  • 買方自行變更造成的問題：如自行改動設定、金鑰、程式碼、或誤刪資料。
  • 資料救援：非因程式缺陷造成的資料遺失（備份與還原協助另計）。

上述項目可依需求按次計費或併入下方「長期維護方案」。

四、長期維護方案（選配） 月費 / 年費

若買方希望有人長期把系統顧好，可加購維護方案，費用 ＿＿＿＿ /月（或 ＿＿＿＿ /年）。內容包含：

  • 監控網站與資料庫運作（含保活、備份、排程維持啟用）。
  • 發生狀況時的處理與排除。
  • 免費額度接近上限、需要升級付費時，主動提醒與協助。
  • 系統小幅更新與安全維護。

不含第三方服務本身的付費方案費用（仍由買方支付）。

五、買方自行負責事項

  • 妥善保管各服務的帳號、密碼與金鑰（外洩風險由買方承擔）。
  • 網域每年續約、各第三方服務的付費升級與帳單。
  • 定期維護動作（如每 1～2 個月確認 GitHub 排程未被停用），詳見《開站手冊》最後「長期維護」章節。
  • 網站上架的內容與其合法性、以及對學員的客服。
